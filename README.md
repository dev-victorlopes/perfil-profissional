## 🚀 Como Usar

### Portfólio Web
Abra o `index.html` no navegador ou sirva localmente:

```bash
python3 -m http.server 8000
# Acesse: http://localhost:8000
```

### Painel Administrativo
Abra `admin/index.html` no navegador. Login local com localStorage.

### Gerenciar GitHub via CLI
```bash
source .venv/bin/activate
python scripts/github_projects_manager.py
```
