# Perfil Profissional Digital — Victor Lopes

Projeto para construção e automação da presença profissional digital.

## Objetivo

Criar uma presença profissional coerente e realista para:
- Busca de estágio em tecnologia
- Oportunidades de desenvolvedor Python júnior
- Desenvolvimento web/backend
- Automação e integração de sistemas

## Plataformas

1. E-mail profissional
2. LinkedIn
3. GitHub
4. Instagram profissional
5. Portfólio web (Vercel)

Ver `PROJECT_STATUS.md` para o estado atual.

## Segurança

Nunca commitar:
- CPF
- Senhas
- Tokens
- API keys
- `.env` com valores reais

Ver `.gitignore` e `.env.example` para detalhes.

## Como usar

Abra o `index.html` no navegador ou serve com:
```bash
python3 -m http.server 8000
```
