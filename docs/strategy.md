# Professional Profile — Documentação do Projeto

Este projeto visa construir a presença profissional digital de Victor Lopes, com foco em oportunidades de estágio e desenvolvimento Python júnior.

## Visão Geral

O objetivo é criar uma identidade profissional coerente e honesta em múltiplas plataformas, demonstrando capacidades técnicas reais e potencial de crescimento.

## Plataformas Alvo

1. **E-mail profissional** — Contato principal para oportunidades
2. **LinkedIn** — Rede profissional, busca de vagas
3. **GitHub** — Portfólio técnico, código aberto
4. **Instagram profissional** — Presença complementar, conteúdo técnico
5. **Portfólio web** — Site pessoal hospedado na Vercel

## Princípios

- **Veracidade**: Nunca exagerar habilidades ou experiência
- **Consistência**: Mesma identidade em todas as plataformas
- **Segurança**: Nunca expor dados sensíveis (CPF, senhas, tokens)
- **Automação**: Automatizar o que for possível, intervir humanamente onde necessário
- **Qualidade**: Funcional antes de bonito, mas ambos importam
